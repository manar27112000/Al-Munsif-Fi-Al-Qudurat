# المنصف في القدرات — نسخة أندرويد

تطبيق أندرويد بيسحب رسائل جروب تليجرام (بحسابك أنتِ) ويحوّلها لعرض PowerPoint مرتب، من الموبايل نفسه من غير ما تحتاجي كمبيوتر أو ملف تصدير.

## بيعمل إيه
- يسجّل دخول بحسابك (كود يوصلك جوه تطبيق تليجرام، وكلمة سر التحقق بخطوتين لو مفعّلة).
- تختاري الجروب، وتاريخ من/إلى، والفجوة بالثواني.
- يطلّع PPTX: من غير أسماء ولا صور شخصية، صور بجودتها الأصلية، النص والصورة في نفس الشريحة، رسايل نفس الشخص المتتالية مجمّعة، الأسئلة المختلفة في شرائح منفصلة، المكرر بيتشال (أول واحدة بس تفضل)، وأي `@handle` أو رسالة "الرسالة موجهة من حساب … 🆔" بتتمسح.
- العربي مظبوط من اليمين لليسار.
- تشاركي الملف أو تحفظيه أو تفتحيه.

## أول استخدام
1. نزّلي `AlMunsif.apk` من صفحة **Releases** في الريبو، وثبّتيه (الموبايل هيطلب السماح بالتثبيت من المتصفح).
2. التطبيق هيطلب `api_id` و`api_hash`: افتحي <https://my.telegram.org/apps>، سجّلي دخول، واعملي تطبيق (أي اسم)، وانسخي القيمتين. بيتعملوا مرة واحدة بس.
3. اكتبي رقمك بالصيغة الدولية، وبعدين الكود اللي هيوصلك في محادثة **Telegram** جوه تطبيق تليجرام.

## ملاحظات
- سيبي التطبيق مفتوح لحد ما التصدير يخلص (الشاشة بتفضل منوّرة).
- التطبيق بيستخدم حسابك بشكل عادي (زي أي تطبيق تليجرام تاني)؛ سحب آلاف الرسايل بسرعة ممكن تليجرام يطلب منه ينتظر شوية وهو بيعمل كده تلقائي.
- بيانات الدخول (الجلسة) بتتخزن على موبايلك بس. زرار "تسجيل خروج" بيمسحها.

## البناء
GitHub Actions بيبني الـ APK تلقائيًا (`.github/workflows/build-android-apk.yml`) وينشره في Releases باسم `AlMunsif.apk`.

التركيب: واجهة Java (Views عادية) + [Chaquopy](https://chaquo.com/chaquopy/) لتشغيل بايثون جوه التطبيق.
- `app/src/main/python/munsif_core.py` — التنظيف والتجميع وإزالة المكرر.
- `app/src/main/python/pptx_writer.py` — كاتب PPTX من غير مكتبات خارجية.
- `app/src/main/python/tg_source.py` و`bridge.py` — الاتصال بتليجرام عن طريق [Telethon](https://github.com/LonamiWebs/Telethon).
- `app/src/main/java/.../Ige.java` — تشفير AES-IGE سريع عن طريق جافا (بدل بايثون البطيء).
- `app/src/main/python/pyaes/` — مكتبة pyaes (ترخيص MIT) متضمنة لأنها مش بتتثبّت تلقائيًا.

## اختبار منطق البايثون على الكمبيوتر
```
python tests/test_core.py tests/fixture.zip out.pptx 60
```
